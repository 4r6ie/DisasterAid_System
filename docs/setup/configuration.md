# Configuration

Related notes: [[README]] · [[docs/setup/installation]] ·
[[docs/operations/docker]]

There are two environment files:

| File | Read by | Purpose |
| --- | --- | --- |
| `backend/.env` | the Laravel application | PHP, database, cache, mail, Sanctum |
| `.env` (repo root) | Docker Compose only | Ports, database name, seed admin |

## Backend variables

### Application

| Variable | Default | Notes |
| --- | --- | --- |
| `APP_NAME` | `DisasterAid System` | |
| `APP_ENV` | `local` | `local`, `testing`, `production` |
| `APP_KEY` | — | Generated by `php artisan key:generate` |
| `APP_DEBUG` | `true` | Set `false` in production |
| `APP_URL` | `http://localhost` | |
| `LOG_CHANNEL` | `stack` | |
| `LOG_LEVEL` | `debug` | |

### Database

| Variable | Default | Notes |
| --- | --- | --- |
| `DB_CONNECTION` | `pgsql` | |
| `DB_HOST` | `127.0.0.1` | `postgres` inside Docker |
| `DB_PORT` | `5432` | |
| `DB_DATABASE` | `disasteraid` | |
| `DB_USERNAME` | `disasteraid` | |
| `DB_PASSWORD` | `disasteraid` | |

### Cache, session and queue

| Variable | Default | Notes |
| --- | --- | --- |
| `CACHE_STORE` | `file` | Required — Laravel 11+ defaults to `database` |
| `CACHE_DRIVER` | `file` | Legacy alias, kept for compatibility |
| `SESSION_DRIVER` | `file` | |
| `SESSION_LIFETIME` | `120` | Minutes |
| `QUEUE_CONNECTION` | `sync` | |

### Mail

`MAIL_MAILER=log` by default, so password-reset mails are written to the log
instead of being sent. Configure `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`,
`MAIL_PASSWORD` and `MAIL_ENCRYPTION` for a real transport.

### Authentication

| Variable | Default | Notes |
| --- | --- | --- |
| `SANCTUM_STATEFUL_DOMAINS` | `localhost,localhost:5173` | Domains allowed to use session auth |
| `SESSION_DOMAIN` | `localhost` | |

### Seeding

| Variable | Default | Notes |
| --- | --- | --- |
| `ADMIN_EMAIL` | `admin@disasteraid.test` | Used by `AdminUserSeeder` |
| `ADMIN_PASSWORD` | — (required in production) | Used by `AdminUserSeeder`; falls back to `password` locally |
| `SEED_DEMO_USERS` | `false` | Set `true` locally to create the four demo accounts |
| `DEMO_PASSWORD` | — (required when demo seeding) | Shared password for the demo accounts; no default |
| `CORS_ALLOWED_ORIGINS` | — (empty blocks all) | Comma-separated browser origins allowed to call the API |

### Activity log

| Variable | Default | Notes |
| --- | --- | --- |
| `ACTIVITY_LOG_TABLE_NAME` | `audit_logs` | Spatie activity log table |

## Root (Docker Compose) variables

| Variable | Default | Notes |
| --- | --- | --- |
| `APP_PORT` | `8000` | Host port for the API |
| `DB_PORT` | `5432` | Host port for PostgreSQL |
| `DB_DATABASE` | `disasteraid` | Must match `backend/.env` |
| `DB_USERNAME` | `disasteraid` | |
| `DB_PASSWORD` | `disasteraid` | |
| `ADMIN_EMAIL` | `admin@disasteraid.test` | Seed account |
| `ADMIN_PASSWORD` | `password` | Seed account |

The backend service overrides `DB_HOST=postgres` and `DB_CONNECTION=pgsql`
inside the container; every other value comes from `backend/.env`.

## Config files

| File | Contents |
| --- | --- |
| `backend/config/app.php` | Providers, aliases, name, URL |
| `backend/config/auth.php` | `web` and `sanctum` guards, user provider |
| `backend/config/database.php` | PostgreSQL connection, migrations table |
| `backend/config/sanctum.php` | Sanctum guard and expiration |
| `backend/config/permission.php` | Spatie permission models and tables |
| `backend/config/activitylog.php` | Spatie activity log settings |
| `backend/bootstrap/app.php` | Middleware, rate limiting, JSON error envelope |
| `frontend/vite.config.ts` | Dev server, `/api` proxy target |
| `frontend/tailwind.config.js` | Theme colors and content paths |
